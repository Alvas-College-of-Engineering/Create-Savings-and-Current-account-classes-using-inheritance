# Bank Account Management System

A simple Java-based Bank Account Management System developed using Object-Oriented Programming concepts such as inheritance, encapsulation, and polymorphism.

This project demonstrates the implementation of Savings Account and Current Account classes using inheritance in Java. The application also includes a basic web-based interface using Java HttpServer.

---

## Features

- Create Savings and Current Accounts
- Deposit and Withdraw Money
- Balance Management
- Transaction Handling
- Inheritance-based Class Structure
- Simple Web Interface
- Maven Project Structure

---

## Technologies Used

- Java 17
- Maven
- HTML & CSS
- Java HttpServer

## How to Run the Project

### Clone the Repository

```bash
git clone https://github.com/Alvas-College-of-Engineering/Create-Savings-and-Current-account-classes-using-inheritance.git
```

### Open Project

Open the project in VS Code or any Java IDE.

### Run Using Maven

```bash
mvn compile
mvn exec:java
```

---

## Output

The application starts a local web server where users can:

- Manage bank accounts
- Perform transactions
- View account details
